# Анализ временного ряда продаж Online Retail

Домашняя работа № 1 по курсу «Прогнозирование временных рядов и обработка сигналов». Цель — оценить качество и структуру ряда продаж перед прогнозированием.

Выбран товар **85099B — большая красная сумка в горошек**. Он занимает второе место по числу строк подтверждённых продаж и отдельных счетов, третье по числу исходных строк и пятое по сумме проданных единиц. Лидер по частотности — `85123A`, разобранный на занятии. Показатель — валовые продажи в штуках по всем странам: отмены, возвраты, служебные строки и строки с неположительными количеством или ценой исключены из показателя.

## Запуск

Нужен Python 3.10 или 3.11. Из папки проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab hw1.ipynb
```

Запустите все ячейки по порядку. Выводы и графики уже сохранены в ноутбуке. Для повторного запуска используется `data/Online Retail.xlsx`: если файла нет, ноутбук скачает официальный архив. Можно также скачать его вручную со [страницы UCI](https://archive.ics.uci.edu/dataset/352/online+retail) и распаковать таблицу в `data/`.

## Файлы

- [Ноутбук](hw1.ipynb) — от загрузки данных до интерпретации тестов.
- [Расчёты](analysis.py) и [графики](plots.py) вынесены в отдельные функции.
- [Дневной](results/daily.csv), [недельный](results/weekly.csv) и [месячный](results/monthly.csv) ряды. Поле `sales` — сумма записанных продаж в штуках; пустая ячейка означает отсутствие наблюдения. Недельная дата — воскресенье, месячная — первое число месяца. В агрегатах есть число наблюдаемых и ненаблюдаемых дней; `full_period` означает, что весь календарный период попал в границы выгрузки.

Источник: Д. Чен (2015), [Online Retail](https://doi.org/10.24432/C5BW33), UCI Machine Learning Repository, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Результаты и выводы

1. **Данные и частота.** В исходной таблице 541 909 строк за 01.12.2010–09.12.2011. Для `85099B` учтены 2 112 строк с продажами 48 474 единиц. Коэффициент вариации падает с 1,19 для дней до 0,53 для полных недель и 0,33 для полных месяцев. Недельная частота даёт 51 наблюдаемую сумму на 52 полных календарных недели. Полных месяцев только 12; недельная частота лучше сохраняет длину ряда.
2. **Качество.** Из 374 дней в 300 были продажи товара, ещё в 5 наблюдался ноль при активном магазине. В 69 датах записей магазина нет, включая 53 субботы и неделю 27.12.2010–02.01.2011. Они не заменены нулями в исходном ряду. Локальное медианное абсолютное отклонение выделило одну неделю — до 13.11.2011, 2 200 шт., из них 1 000 шт. в одной строке. Всплеск сохранён: оснований считать его ошибкой нет.
3. **Тренд и сезонность.** В наблюдаемой части IV квартала 2011 года средний недельный объём (1 290 шт.) и стандартное отклонение (677 шт.) выше, чем во II квартале (775 и 301 шт.). В дневной устойчивой STL с периодом 7 сила недельной компоненты — 0,22. Для расчёта использованы 53 условных субботних нуля и 16 локальных оценок. Проверка на наблюдаемых днях подтверждает различие по дням недели (Фридман: 44 недели, p ≈ 6,21 × 10⁻⁷, W = 0,17); воскресная медиана — 30 шт. Связь после удаления тренда на лаге 7 слабая (0,11). Есть недельный календарный ритм, но мало оснований ожидать сильного и неизменного сезонного профиля. Годовую сезонность по этой истории оценить нельзя.
4. **Стационарность.** На непрерывном участке из 48 полных наблюдаемых недель исходные суммы не дают согласованного результата в пользу стационарности (ADF p ≈ 8,15 × 10⁻⁷; KPSS p ≈ 0,0356). Деление на число наблюдаемых дней это не исправило (KPSS p ≈ 0,0431). После взятия первых разностей ADF отклоняет единичный корень (p ≈ 0,0153), а KPSS не отклоняет стационарность (p ≥ 0,10). Первые разности стоит рассматривать для моделей, которым нужен стационарный вход, и сравнить с явным моделированием тренда на временной валидации. Исходные суммы сохранены.

Ряд пригоден для пробного прогнозирования зарегистрированных недельных продаж. Отсутствие данных о наличии товара не позволяет отделить спрос от ограничений запасов; неполные краевые периоды и известные разрывы нужно учитывать при оценке будущей модели.
